# 中文发布说明

本文件用于整理适合中文场景下的仓库发布信息、简介和版本说明模板。

## 1. 中文仓库简介

### 短简介

基于 PySide6、Pillow 和 OpenCV 的桌面图像编辑工具，支持裁剪、缩放、网格变形、透视矫正、文字图层和高清导出。

### 标准简介

FrameMorph-python 是桌面应用“形绘”的项目仓库。形绘面向本地图像处理工作流，使用 PySide6、Pillow 和 OpenCV 构建，提供裁剪、缩放、旋转、网格变形、透视矫正、文字叠加和高清导出等能力，并支持 OpenCV 超分模型加载、模型下载以及后台导出进度反馈。
