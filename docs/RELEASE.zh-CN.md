# 中文发布说明

本文件用于整理适合中文场景下的仓库发布信息、简介和版本说明模板。

## 1. 中文仓库简介

### 短简介

基于 PySide6、Pillow、OpenCV 和 Python 文档处理库的本地桌面工具，支持图片编辑、文档转换、PDF 处理、OCR 工作流和高清导出。

### 标准简介

FrameMorph-python 是桌面应用“形绘”的项目仓库。形绘面向本地文件处理和图片编辑工作流，使用 PySide6、Pillow、OpenCV、PyMuPDF、pypdf、python-docx 和 openpyxl 构建，提供文档转换、PDF 工具、OCR 路线、去水印任务、图片裁剪变换、文字叠加和高清导出等能力，并支持本地后端检测与批量任务执行。
