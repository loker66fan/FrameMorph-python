# 使用文档

## 1. 环境要求

- Python 3.11 或更高版本
- 安装依赖：

```bash
pip install -r requirements.txt
```

## 2. 启动方式

在项目目录运行：

```bash
python main.py
```

## 3. 基本操作

### 3.1 打开图片

- 点击顶部“打开图片”
- 或直接把图片拖到主画布

支持格式：

- `.png`
- `.jpg`
- `.jpeg`

### 3.2 裁剪

进入“裁剪”页后可以：

- 选择比例
- 拖动裁剪框
- 点击“应用裁剪”

### 3.3 缩放 / 拉伸 / 旋转

进入“变换”页后可以：

- 修改宽高
- 保持比例缩放
- 自由拉伸
- 宽高互换
- 左右旋转 90°
- 自定义旋转角度

### 3.4 网格变形

进入“网格”页后可以：

- 调整网格行列
- 重建网格
- 拖动控制点
- 使用“收缩预设 / 膨胀预设”
- 点击“应用网格变形”

### 3.5 透视变换

进入“透视”页后可以：

- 拖动四个角点
- 点击“应用透视变换”

### 3.6 文字图层

进入“文字”页后可以：

- 新增文字图层
- 修改文字内容、字号、颜色、粗体
- 切换显隐
- 删除当前图层
- 直接在画布上拖动文字位置

## 4. 高清导出

进入“导出”页后可以：

- 选择导出质量
- 选择是否开启增强
- 选择增强方式
- 查看导出前后预览
- 点击“导出当前图片”

## 5. 三种增强方式说明

### 5.1 超分辨率重建技术

- 不依赖外部模型
- 速度较快
- 适合普通高清导出

### 5.2 PyTorch SRCNN

- 需要手动提供 `.pth` 或 `.pt` 模型
- 适合已经准备好 SRCNN 模型文件的情况

### 5.3 OpenCV dnn_superres

支持模型：

- EDSR
- ESPCN
- FSRCNN
- LapSRN

支持能力：

- 选择模型
- 选择倍率
- 选择本地 `.pb` 文件
- 一键下载训练模型到本地
- 打开训练资料 / 实现代码 / 论文

## 6. 使用 `dnn_superres` 的正确方法

### 推荐方式

1. 先选择模型，例如 `EDSR`
2. 再选择倍率，例如 `x4`
3. 点击“下载模型”或手动选择本地 `.pb`

### 自动识别

如果你选择的文件名类似：

- `EDSR_x4.pb`
- `ESPCN_x3.pb`
- `FSRCNN_x4.pb`
- `LapSRN_x8.pb`

程序会自动识别：

- 模型类型
- 放大倍率

### 注意事项

模型文件必须和当前选择一致。

例如：

- `EDSR_x4.pb` 应搭配 `EDSR + x4`
- `LapSRN_x8.pb` 应搭配 `LapSRN + x8`

如果不一致，预览区会显示明确错误提示。

## 7. 导出进度与取消

现在导出不是卡死等待，而是会弹出导出进度窗口，显示：

- 当前进度百分比
- 当前阶段
- 预计剩余时间

支持：

- 点击“取消导出”中止当前任务

## 8. 常见问题

### 8.1 导出预览失败

常见原因：

- 模型文件路径错误
- 模型类型和倍率不匹配
- OpenCV 缺少 `dnn_superres`

### 8.2 导出图片太大

建议：

- JPEG 导出时适当降低质量
- PNG 导出用于无损保真，体积通常更大
- 超分倍率越高，导出体积通常越大

### 8.3 导出速度慢

常见原因：

- 图片尺寸过大
- 使用了 EDSR 等较慢模型
- 同时开启高清增强

### 8.4 右侧面板内容太多

当前右侧控制面板支持滚动，可直接向下滑动查看全部内容。

## 9. 模型文件存放位置

自动下载的 OpenCV 超分模型默认放在：

```text
models/opencv_dnn_superres/
```

## 10. 建议使用流程

推荐顺序：

1. 导入图片
2. 完成裁剪 / 变换 / 网格 / 透视
3. 添加文字图层
4. 进入导出页做增强预览
5. 确认效果后导出
