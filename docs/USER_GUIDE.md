# 使用文档

## 1. 环境要求

- Python 3.11 或更高版本
- 安装依赖：

```bash
pip install -r requirements.txt
```

## 2. 启动方式

在项目目录运行：

```bash
python main.py
```

## 3. 基本操作

启动后左侧一级导航包含：

- 文档工作台
- 图片工作台
- 设置

文档、PDF、OCR 和批量图片任务在“文档工作台”完成；原有画布编辑和高清导出在“图片工作台”完成。

## 4. 文档工作台

### 4.1 模块选择

文档工作台提供以下模块：

- 文档转换
- PDF 工具
- 图片工具
- OCR 识别
- 去水印

切换模块后，源格式、目标动作、说明、可用后端和拖拽提示会随模块更新。

### 4.2 文件池与任务队列

常用流程：

1. 拖入文件，或点击“添加文件 / 导入目录”
2. 选择目标动作
3. 点击“加入任务队列”
4. 点击“执行全部”或“执行选中”
5. 在日志和任务队列中查看结果

输出默认写入：

```text
output/document_workbench/
```

也可以在“设置”页修改默认输出目录。

### 4.3 当前接入的任务

文档转换：

- Office 转 PDF
- PPT 转图片
- Markdown / HTML / TXT 转 DOCX、EPUB、HTML、MD、TXT
- 表格转 CSV

PDF 工具：

- PDF 转图片
- PDF 拆分与合并
- PDF 压缩、旋转、加密、解密
- PDF OCR 文本识别
- PDF 文字水印处理

图片工具：

- 图片转 PDF
- 图片转 PNG / JPG
- PDF 转 PNG / JPG
- 图片压缩、裁剪、缩放和批量处理

OCR 识别：

- 图片 / PDF 转 TXT
- 图片 / PDF 转 DOCX
- 图片 / PDF 转 XLSX
- 图片 / PDF 转可搜索 PDF

去水印：

- PDF 文本水印删除
- 图片文字水印删除
- 图片修复和背景填充

### 4.4 本地后端要求

部分任务需要本机安装外部命令行工具：

- LibreOffice / `soffice`
- Pandoc
- Poppler 工具，如 `pdftoppm`、`pdfinfo`
- Tesseract OCR
- FFmpeg

文档工作台和设置页会显示当前机器的后端检测结果。未检测到的工具不会影响应用启动，但相关任务可能无法执行。

## 5. 图片工作台

### 5.1 打开图片

- 点击顶部“打开图片”
- 或直接把图片拖到主画布

支持格式：

- `.png`
- `.jpg`
- `.jpeg`

### 5.2 裁剪

进入“裁剪”页后可以：

- 选择比例
- 拖动裁剪框
- 点击“应用裁剪”

### 5.3 缩放 / 拉伸 / 旋转

进入“变换”页后可以：

- 修改宽高
- 保持比例缩放
- 自由拉伸
- 宽高互换
- 左右旋转 90°
- 自定义旋转角度

### 5.4 网格变形

进入“网格”页后可以：

- 调整网格行列
- 重建网格
- 拖动控制点
- 使用“收缩预设 / 膨胀预设”
- 点击“应用网格变形”

### 5.5 透视变换

进入“透视”页后可以：

- 拖动四个角点
- 点击“应用透视变换”

### 5.6 文字图层

进入“文字”页后可以：

- 新增文字图层
- 修改文字内容、字号、颜色、粗体
- 切换显隐
- 删除当前图层
- 直接在画布上拖动文字位置

## 6. 高清导出

进入“导出”页后可以：

- 选择导出质量
- 选择是否开启增强
- 选择增强方式
- 查看导出前后预览
- 点击“导出当前图片”

## 7. 三种增强方式说明

### 7.1 超分辨率重建技术

- 不依赖外部模型
- 速度较快
- 适合普通高清导出

### 7.2 PyTorch SRCNN

- 需要手动提供 `.pth` 或 `.pt` 模型
- 适合已经准备好 SRCNN 模型文件的情况

### 7.3 OpenCV dnn_superres

支持模型：

- EDSR
- ESPCN
- FSRCNN
- LapSRN

支持能力：

- 选择模型
- 选择倍率
- 选择本地 `.pb` 文件
- 一键下载训练模型到本地
- 打开训练资料 / 实现代码 / 论文

## 8. 使用 `dnn_superres` 的正确方法

### 推荐方式

1. 先选择模型，例如 `EDSR`
2. 再选择倍率，例如 `x4`
3. 点击“下载模型”或手动选择本地 `.pb`

### 自动识别

如果你选择的文件名类似：

- `EDSR_x4.pb`
- `ESPCN_x3.pb`
- `FSRCNN_x4.pb`
- `LapSRN_x8.pb`

程序会自动识别：

- 模型类型
- 放大倍率

### 注意事项

模型文件必须和当前选择一致。

例如：

- `EDSR_x4.pb` 应搭配 `EDSR + x4`
- `LapSRN_x8.pb` 应搭配 `LapSRN + x8`

如果不一致，预览区会显示明确错误提示。

## 9. 导出进度与取消

现在导出不是卡死等待，而是会弹出导出进度窗口，显示：

- 当前进度百分比
- 当前阶段
- 预计剩余时间

支持：

- 点击“取消导出”中止当前任务

## 10. 设置

设置页目前包含：

- 主题切换
- 软件字体大小
- 默认输出目录选择与打开
- 本地后端状态刷新

主题、字体大小和输出目录会写入本地配置文件，并在下次启动时恢复。

## 11. 常见问题

### 11.1 文档任务执行失败

常见原因：

- 未安装任务需要的外部工具，例如 LibreOffice、Pandoc、Tesseract 或 Poppler
- 输入格式和当前目标动作不匹配
- PDF 加解密口令不正确
- 输出目录没有写入权限

可以先查看任务队列详情和日志中的错误码，再到设置页刷新环境状态。

### 11.2 启动时提示 PyQt / PySide 冲突

本项目使用 `PySide6` 和 `PySide6-Fluent-Widgets`。如果当前 Python 环境同时安装了 PyQt5 版 Fluent Widgets，并且 `qfluentwidgets` 命名空间被 PyQt5 版占用，应用会提示依赖冲突并退出。

建议在干净虚拟环境中重新安装：

```bash
pip install -r requirements.txt
```

### 11.3 导出预览失败

常见原因：

- 模型文件路径错误
- 模型类型和倍率不匹配
- OpenCV 缺少 `dnn_superres`

### 11.4 导出图片太大

建议：

- JPEG 导出时适当降低质量
- PNG 导出用于无损保真，体积通常更大
- 超分倍率越高，导出体积通常越大

### 11.5 导出速度慢

常见原因：

- 图片尺寸过大
- 使用了 EDSR 等较慢模型
- 同时开启高清增强

### 11.6 右侧面板内容太多

当前右侧控制面板支持滚动，可直接向下滑动查看全部内容。

## 12. 模型文件存放位置

自动下载的 OpenCV 超分模型默认放在：

```text
models/opencv_dnn_superres/
```

## 13. 建议使用流程

图片编辑推荐顺序：

1. 导入图片
2. 完成裁剪 / 变换 / 网格 / 透视
3. 添加文字图层
4. 进入导出页做增强预览
5. 确认效果后导出

文档工作台推荐顺序：

1. 切换到目标模块
2. 拖入或选择文件
3. 选择目标动作
4. 加入任务队列
5. 执行任务并检查输出目录
