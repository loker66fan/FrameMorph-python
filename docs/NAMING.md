# Naming Convention

## Project Name

`FrameMorph-python`

Used for:

- repository name
- README title
- release materials
- build package naming
- project summary and public-facing repo metadata

## Application / Software Name

`形绘`

Used for:

- window title
- desktop app display name
- user-facing runtime naming inside the GUI

## Naming Rule

When writing documentation or release metadata:

- refer to the repository/project as `FrameMorph-python`
- refer to the desktop software itself as `形绘`
