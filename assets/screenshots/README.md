# Screenshot Assets

Place release screenshots in this directory.

Recommended filenames:

- `document-workbench.png`
- `workbench.png`
- `export-panel.png`
- `mesh-warp.png`
- `settings-page.png`

Current coverage:

- `document-workbench.png` shows module navigation, file pool, task queue, environment status, and logs
- `workbench.png` shows the image canvas and right-side editing panels
- `mesh-warp.png` shows mesh warp controls and overlay points
- `export-panel.png` shows enhancement settings and export preview controls
- `settings-page.png` shows appearance, output directory, and environment settings

Suggested capture rules:

- Use a reasonably large window size
- Prefer clean sample images
- Avoid personal or sensitive content
- Keep UI language consistent within a release

These files are generated by:

```bash
QT_QPA_PLATFORM=offscreen python scripts/capture_readme_screenshots.py
```

The script captures the real Qt window when the PySide6 Fluent Widgets namespace is available. If the local Python environment has the PyQt5 Fluent Widgets package occupying the same `qfluentwidgets` namespace, the script creates non-destructive fallback release images for missing document/settings screenshots instead of overwriting existing real screenshots.

The script also creates `_sample_input.png`, which is only used as a safe local demo asset for screenshots.
